# 词跃 WordLeap · 系统设计与功能说明

> 课程：《Web智能化》结课项目 ｜ 题目：英语单词背诵智能化系统  
> 版本：v1.0（2026-11-07）｜ 本文档只包含设计与功能，不含课程报告正文。

## 一、设计主题

**主视觉「墨绿书卷」**：把背单词做成一本耐读的纸书——米白纸感底、墨绿主色、陶土橙强调。

选择理由：

1. 背单词是长时间近距离阅读场景，低饱和暖底 + 深绿能降低视觉疲劳；
2. 墨绿与纸张的组合带有「词典 / 书卷」的语义，比常见的蓝紫渐变更贴合学习场景；
3. 强调色只用陶土橙与金，形成稳定语义：橙 = 需要注意（待复习 / 易错），金 = 成就与奖励。

**夜间主题「深夜极光」**：深蓝黑底 + 长春花蓝 + 薄荷绿，用同一套 CSS 变量切换，不另做一套页面。

系统名：**词跃 WordLeap**  
Slogan：**让每个单词，都在该忘记之前重逢。**

## 三、页面结构

```
/login                 登录 / 注册 / 找回密码（左右分栏）
/dashboard             仪表盘
/learn                 今日学习（沉浸式学习页）
/books                 词书库
/books/:id             词书详情（独立完整页）
/review                智能复习
/wrong                 错词本
/garden                词汇森林
/arena                 听写擂台
/stats                 学习统计
/achievements          我的成就
/profile               个人中心
```

- 全局骨架：左侧栏（学习中心 / 数据中心两组）+ 顶栏（面包屑、搜索、主题、通知、日期、头像）+ 内容区。
- 学习页为沉浸模式：隐藏侧栏，只保留顶部进度、计时与「结束本轮」。
- 响应式：≥1200px 三栏；768–1199px 收窄侧栏；<768px 单列卡片 + 底部 Tab（首页 / 词书 / 学习 / 统计 / 我的）。
- 路由懒加载 + 登录守卫：未登录访问业务页跳登录并记录 redirect；已登录访问登录页回仪表盘；页面标题随路由更新。

## 四、功能清单

### 1. 账号与认证

- 登录 / 注册 / 找回密码三个 Tab；登录支持账号密码、记住我（7 天）、演示账号一键填入。
- 注册字段：昵称、账号（手机号 / 邮箱）、学号、院校、密码、确认密码、协议勾选；逐项校验并即时提示。
- 登录后自动加入「大学英语四级核心词汇」，进入仪表盘。
- 退出登录二次确认；退出只清理会话，保留本机学习记录。
- 找回密码为本地演示说明页：提示本地账号无法邮件找回，引导使用演示账号 / 注册新账号，或到个人中心直接改密。
- 密码本地哈希后存 localStorage（课程演示，不涉及真实加密传输）。

### 2. 仪表盘

- 按时段问候 + 今日专注时长 + 考试倒计时。
- 今日记忆任务 Hero：进度环、新词 / 复习 / 听写配比、预计时长、继续学习。
- 今日三任务：学习 20 个新词、复习 10 个到期词、完成 1 次听写；全部完成可开宝箱，奖励补签卡 / 双倍经验 / 冻结卡 / 词币。
- 4 张 KPI：今日已学、累计掌握、连续打卡、待复习。
- 遗忘曲线与复习干预：复习后保持率 vs 未复习衰减对照。
- 词书进度、26 周学习足迹热力图、最近成就、今日听写挑战入口。

### 3. 今日学习（核心闭环）

- 三种模式：认词（看词选义）、拼写（看中文拼英文）、听音（听发音拼写）。
- 本轮设置：词书范围、10 / 20 / 30 词、取词来源（智能计划 / 只复习到期 / 错词强化）。
- 单词卡：词性、考纲标签、音标、中英释义、例句与翻译、词根词缀记忆、常用搭配、近义词；发音不自动播放，只有点击扬声器按钮才朗读。
- 作答三档：不认识 / 有点模糊 / 认识，对应不同的记忆稳定度与掌握度变化；支持 1 / 2 / 3 键与空格显示释义。
- 反馈：正确 / 错误动效、连击、掌握度环、本轮队列（按遗忘曲线动态排序）。
- 结束本轮：结算页显示学习词数、答对、新词 / 复习、最高连击、经验、用时、等级进度、解锁成就，并给出下一轮建议；可生成学习战报海报：Canvas 绘制 1080×1350 PNG，支持系统分享、保存图片、复制文案。
- 错词自动进错词本；本轮进度写入 localStorage，刷新可恢复。

### 4. 词书库

- 8 本词书：四级、六级、雅思、考研、托福、GRE、商务 BEC、学术写作；按类型筛选 + 名称搜索。
- 我的词书 / 发现词书分区；加入、移出、设为主修、继续学习。
- 词书详情独立页：封面色块、标称 / 演示 / 已学 / 掌握统计、掌握环、词表搜索与词级掌握标签、考试倒计时、学习建议、加入 / 开始本轮 / 设主修 / 移出词书。
- 新建 / 导入词书：名称、类型、简介、逐行词条（支持「单词 释义」或「单词 /音标/ 词性. 释义」），创建前显示识别到的有效词条数。
- 自建词书持久化到 localStorage，可直接参与学习与统计。

### 5. 智能复习

- 到期队列：按可提取概率升序，越接近遗忘越靠前；显示记忆保持率、掌握度、上次复习时间。
- 复习概览：待复习数、预计复习后保持率、7 天到期预测柱状图。
- 复习设置弹窗：每日目标词数、每日复习上限、智能复习优先；所有朗读均由点击扬声器触发，不自动发音。
- 复习工具：补签卡（仅补最近一天断签，无断签不扣卡）、连续冻结卡、双倍经验卡，道具保存在本地账号背包。
- 一键开始复习，进入与学习页一致的三档评价流程。

### 6. 错词本

- 做错 / 评价「不认识」的词自动收进来；按错误次数、最近复习排序。
- KPI：错词总数、高频错误、平均掌握度、已消灭。
- 搜索 + 词书 / 掌握度筛选 + 排序切换；行内查看词条详情、移除、立即复习。
- 导出错词清单；错误次数 ≥3 的词建议用拼写模式强化。
- 掌握度达到阈值后可移出，形成「错 → 练 → 消灭」闭环。

### 7. 词汇森林（长期成长）

- 每掌握 10 个单词种下一棵树；共 30 块地，长期积累可见。
- 进入遗忘临界点的词会让树枯萎，及时复习重新变绿。
- 词卡图鉴：每 50 个掌握词抽一张词根 / 词缀卡，共 12 张。
- 成长记录：最近种树 / 学习里程碑。

### 8. 听写擂台（趣味挑战）

- 60 秒限时听写：看中文释义拼英文单词，答对得分、连击加成，可跳过。
- 结算：总分、答对数、正确率、最高连击、获得经验、历史最高分。
- 擂台榜（课程演示数据）、本周赛季段位进度、答题技巧。
- 防重复提交：反馈动画期间禁止再次提交 / 跳过，避免刷分。

### 9. 学习统计

- 数据来自真实学习记录（records / progress），不使用静态图。
- KPI：学习时长、学习词次、平均正确率、记忆保持率。
- 学习趋势（新学 / 复习双线）、词汇掌握分布环图、26 周热力图、星期学习量。
- 薄弱词汇表：错误次数、最近复习、掌握度、一键复习。
- 导出学习报告：弹窗预览本周 / 本月 / 全部数据，支持下载 Markdown、下载纯文本、复制全文、系统分享、打印 / 另存为 PDF；报告含概览、薄弱词，不含密码。

### 10. 我的成就

- 等级 Lv.1–Lv.10，经验来自学习、复习、连续打卡与听写。
- 12 枚徽章：连续 7 天 / 14 天 / 30 天、千词斩、满分小测、早起鸟、夜猫子、月满贯、词王、擂台新星、森林园丁等。
- 徽章墙按「坚持 / 学习 / 挑战」筛选，未解锁显示条件。
- 同桌周榜（课程演示数据）、最近里程碑、生成战报入口（分享 / 保存图片 / 复制文案）。

### 11. 个人中心

- 资料卡：头像文字、昵称、学号 / 班级、等级与经验、连续天数 / 掌握词汇 / 学习小时。
- 基本信息：昵称、真实姓名、学号、班级、邮箱、手机、院校、目标考试、考试日期、每日目标、一句话简介；保存校验 + Toast + 重置。
- 修改密码：原密码、新密码、确认新密码；校验 6–20 位且同时含字母与数字，原密码错误会提示。
- 账号安全：上次改密时间、绑定手机、登录邮箱、退出登录。
- 学习偏好：每日目标、自动发音、每日提醒、智能复习优先、音效反馈、深色模式。
- 成就墙 + 重置演示数据。

### 12. 全局能力

- 全局搜索（Ctrl K）：单词 / 词书结果，点击打开词条详情弹窗。
- 词条详情弹窗：音标、发音、释义、例句、词根、搭配、近义词、掌握度、复习入口。
- 通知中心、头像下拉菜单（个人中心 / 成就 / 主题 / 退出）。
- 浅色 / 深色主题切换并记忆选择。
- Toast、确认弹窗、表单错误、空状态、加载态统一的反馈体系。

## 五、智能算法（纯前端、可解释）

1. 每个单词维护记忆状态：S（记忆稳定度，天）、D（难度）、last（上次复习）、reps、lapses、mastery、wrong、seen、correct。
2. 可提取概率：`R = exp(-Δt / S)`，Δt 为距上次复习天数；R 越低越接近遗忘。
3. 三档评价更新：
   - 不认识：S × 0.5（最低 0.4 天），掌握度 −14，lapses +1；
   - 有点模糊：S × 1.1（最低 1 天），掌握度 +3；
   - 认识：S × 1.9（上限 180 天），掌握度 +9 + min(6, reps)。
4. 到期判断：`last + S 天`；复习队列按 R 升序，优先临界词。
5. 掌握度分档：≥85 熟练、≥60 认识、≥30 模糊、其余生疏。
6. 拼写判定：编辑距离 ≤1 视为拼写正确，并提示「差一个字母」。

## 六、数据模型（localStorage）

| Key | 内容 |
| --- | --- |
| `wl_users` | 用户数组：id、账号、密码哈希、昵称、学号、院校、创建时间 |
| `wl_session` | 当前会话：userId、过期时间、remember |
| `wl_data_{userId}` | 该用户全部学习数据（见下） |
| `wl_theme` | 当前主题 |

`wl_data_{userId}` 内包含：

- `profile`：昵称、真实姓名、学号、班级、邮箱、手机、院校、目标考试、考试日期、每日目标、简介；
- `prefs`：自动发音、提醒、智能复习优先、音效、深色模式；
- `books`：每本词书的加入 / 主修状态；
- `progress`：每个单词的 SRS 状态与掌握度；
- `records`：每日学习记录（新学、复习、正确数、总题数、时长、模式）；
- `items`：补签卡、冻结卡、双倍经验卡、词币；
- `xp`、`achievements`、`tasks`、`arena`、`lastStudyDate`。

演示种子：3 本已加入词书、50 个已学单词、76 条学习记录、780 经验、8/12 枚成就、听写历史最高 42 分。

  - 发音：进入学习卡自动朗读 0 次，点击扬声器按钮朗读 1 次；
  - 浅色 / 深色主题切换成功。
- 截图：桌面 1440px 全页 13 张、移动 390×844@2x 4 张、关键弹窗与流程 15+ 张，均在 `design/app/`。
